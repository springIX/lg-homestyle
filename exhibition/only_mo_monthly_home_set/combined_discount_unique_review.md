# 결합할인 시안 반영 및 확인 사항

대상: `combined_discount_unique.html`
시안: https://www.figma.com/design/BrvWX2b9QLvve5YMiXRZvK?node-id=2004-1653

## 반영 완료

- 메인 비주얼 및 대체 텍스트, 대표 브랜드 제목/설명, 추천 조합 제목, 홈스타일링 제목, LG전자 상품 설명.
- 결제 혜택/캐시백 문구 10% → 시안의 7%.
- 까사미아·알로소 대표 브랜드 배너와 홈스타일링 이미지, 까사미아 상품 목록 배너, 첫구매 배너/문구.
- 교체 이미지 7개 모두 Figma에서 scale=2로 직접 내보냄. 2607과 동일한 파일명 규칙으로 저장하고 실제 픽셀 크기 검증.
- 현재 HTML의 상대 경로를 유지했으며 배포 시 이미지 파일도 함께 업로드 필요.

## 애매해서 기존 유지

- 대표 브랜드: 시안은 까사미아/알로소/아르떼미데 3개, 기존은 루씨에어/알로소/일룸/까사미아/레어로우 5개. 아르떼미데 신규 연결과 기존 브랜드 제거·순서 변경은 보류.
- 추천 조합: 시안은 알로소/브로도/Nessino이며 기존 조합과 다름. 상품명·가격이 같은 예시 데이터로 반복되어 이미지·상품 연결을 유지.
- 홈스타일링: 대응되는 까사미아·알로소 이미지만 교체. 신규 아르떼미데 카드 및 기존 3개 브랜드 제거는 상품 코드 확인 필요. 교체한 이미지에 나온 정확한 상품의 코드도 시안에서 확정할 수 없어 기존 상품 코드를 유지.
- 스페셜 브랜드 상품 탭: 아르떼미데 상품 목록/코드를 확정할 수 없어 기존 탭·상품 유지.
- 패키지 이벤트: 현재 HTML에는 있으나 선택한 시안에 대응 구간이 없어 유지.
- 더 많은 기획전: 남다르게 홈스 세일/남다르게 닷컴 세일은 시안에 '내용 수급 필요'로 표기. 링크와 설명을 확정할 수 없어 기존 카드 유지. 첫구매 카드만 교체.
- 기존 유의사항 및 행사 링크는 유지. 최신 적용 조건·행사 링크 확정 필요.
- 위 보류 구간의 기존 이미지와 API 상품 이미지는 변경하지 않았으며 2배수 여부를 보장하지 않음. 이번에 교체한 7개 이미지는 모두 2배수.

## 검증

- 메인 780×1040, 대표 브랜드 700×176(2개), 홈스타일링 700×700(2개), 상품 배너 700×320, 첫구매 338×246.
- 모든 신규 이미지의 HTML 참조 및 파일 존재 확인.
- 상품 코드, 혼합 상품 키, LG 상품 인덱스 변경 없음 확인.
- 브라우저 화면 및 원격 상품 API 동작 검증은 수행하지 않음.
