핵심요약

스트링퍼니처(STRING FURNITURE)에서 선반을 고른다면 설치 공간과 구성 방식을 기준으로 string pocket과 String System을 비교해 보는 것이 좋습니다. 공간별 구성 모델도 함께 살펴볼 수 있습니다. 설치할 벽면의 폭과 높이를 먼저 확인하는 것이 좋습니다.

본문

스트링퍼니처 선반은 string pocket 단품과 String System 구성 제품으로 나누어 살펴볼 수 있습니다. 한 곳에 가볍게 두려면 string pocket 계열을, 벽면 전체를 구성하려면 공간별 System 모델을 비교하는 방식입니다.
거실에는 String System Living Room G, 책상 공간에는 String System desk set, 복도에는 string hallway, in one box를 살펴볼 수 있습니다. string pocket은 white 외에도 여러 색상 옵션이 있어 공간 분위기에 맞춰 선택할 수 있습니다.
설치할 벽면의 폭과 높이, 놓을 물건의 종류를 먼저 확인하고 구성을 정하는 것이 좋습니다.
