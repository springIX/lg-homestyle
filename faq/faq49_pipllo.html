[가구] 피플로에서 추천하는 가구는 무엇인가요?

핵심요약

피플로(PIPLLO)에서는 실내외 겸용으로 쓸 수 있는 벤치와 테이블, 스툴을 먼저 살펴볼 수 있습니다. 정원이나 테라스에 앉을 자리가 필요하면 FLO 01 벤치와 HILL 벤치를, 야외 테이블이 필요하면 WAVE TABLE이나 CIRCLE TABLE을 고르는 방식이 편합니다.

선택기준

선택기준 표
필요한 기능 살펴볼 제품 추천 상황
여러 명이 앉는 자리 FLO·HILL 벤치 테라스나 정원에 메인 좌석을 만들 때
이동식 보조 좌석 PIXEL STOOL 필요할 때 좌석을 추가하거나 위치를 바꾸고 싶을 때
공간 포인트 테이블 WAVE TABLE 곡선 형태를 활용해 공간에 포인트를 주고 싶을 때
소규모 테이블 CIRCLE TABLE 서로 마주 보는 좌석 구성을 만들 때
식재 공간 FLO PLANTER 식물과 가구를 비슷한 디자인 언어로 구성하고 싶을 때

본문

피플로 가구는 재생 플라스틱으로 코팅한 파이프 구조가 공통 요소입니다. 코팅 파이프는 실내외 겸용에 적합한 내후성을 갖춰 테라스나 정원처럼 외기에 노출되는 자리에도 둘 수 있고, 파이프 사이 여백이 있어 좁은 공간에서도 답답한 느낌이 적습니다.
선택은 자리의 성격에 따라 나뉩니다. 오래 앉아 쉬는 자리라면 여러 명이 나란히 앉는 벤치 라인을, 인원 변동이 잦은 자리라면 옮기기 쉬운 스툴을 함께 두는 편이 좋습니다. 테이블은 사각·원형·곡선 형태가 있어 동선과 좌석 수에 맞춰 고르고, 플랜터까지 같은 색으로 맞추면 공간 톤이 정리됩니다.
LGE.COM 홈스타일에는 현재 PIXEL STOOL, WAVE TABLE, FLO 01 벤치, CIRCLE TABLE 등을 포함한 피플로 제품이 노출되고 있습니다.
